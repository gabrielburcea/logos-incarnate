# Phase 1 Implementation Plan: Genesis 2 Vertical Slice

## Goal

Build a narrow but powerful first implementation that demonstrates the distinctive value of Logos Incarnate through a polished Genesis 2 experience.

This phase should prove that the app can combine reading, manuscript-style study, meaning exploration, and restrained relationship visibility in a single coherent flow.

## Core Outcomes

The Genesis 2 vertical slice should demonstrate:
- a calm and elegant chapter reading experience
- a Study Manuscript Mode that feels different from a standard note app
- persistent annotations that remain visibly attached to the reading surface
- a Meaning Explorer card for selected words
- a small graph preview that adds clarity without overload

## Included Features

### 1. Genesis 2 Reader UI
- render Genesis 2 in a clean reading layout
- display verse numbers
- support a responsive and readable chapter view
- provide a clear entry point into Study Manuscript Mode

### 2. Study Manuscript Mode
- increase verse spacing
- provide annotation affordances
- preserve beauty and readability
- create room for margin-style interaction

### 3. Persistent Annotation Layer
- support highlights
- support underlines
- support handwritten-style margin notes
- preserve annotation placement and appearance on revisit

### 4. Meaning Explorer Card
- support selected Genesis 2 targets only in the first version
- show core meaning
- show occurrence count
- show key related passages
- show concise contextual analysis

### 5. Graph Preview
- show a small graph preview for selected words, people, or themes
- keep node count intentionally limited
- design the graph preview for future expansion

## Out of Scope for Phase 1

- full Bible support
- full graph explorer
- full genealogy engine
- full animation system
- broad multi-translation support
- unrestricted AI chat
- advanced drawing tools

## Suggested Build Order

1. build Genesis 2 reader UI
2. implement Study Manuscript Mode layout
3. add persistent annotation support
4. build Meaning Explorer card for selected words
5. add graph preview for selected targets

## Initial Target Set for Meaning Explorer

Recommended starting targets:
- helper
- woman
- man
- one flesh
- side/rib
- naked / not ashamed

## Acceptance Criteria

Phase 1 is successful if:
- Genesis 2 feels compelling as a reading experience
- Study Manuscript Mode feels distinct and useful
- annotations remain visible and persistent after reopening
- Meaning Explorer gives immediate value on selected targets
- the graph preview is understandable and non-overwhelming
- the product clearly feels different from a conventional Bible app
